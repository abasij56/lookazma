برنامه گام‌به‌گام: product_tag → CPT برند

هر فاز را جداگانه انجام دهید، تست کنید، بعد بروید فاز بعد. رابطه محصول ↔ برند عمداً خالی است تا شما مدلش را بگویید.

تصمیم‌های قفل‌شده

  • CPT برند با URL به شکل /brand/{slug}/
  • ریدایرکت ۳۰۱ از /product-tag/{slug}/ به /brand/{slug}/
  • همه تگ‌های فعلی محصول = برند
  • نوار برند هوم‌پیج از CPT پر شود (نه لینک هاردکد)
  • Attribute Price Editor و ابزارهای برند AI → بعداً
  • کد و slug انگلیسی؛ UI فارسی OK
قفل موقت: طراحی رابطه محصول↔برند خالی است. فازهایی که به آن نیاز دارند با برچسب «مسدود تا فاز R» مشخص شده‌اند و اجرا نمی‌شوند تا شما فرم فاز R را پر کنید.

وضعیت فعلی (قبل از مهاجرت)

برند = تاکسونومی ووکامرس product_tag. محصول با تگ به برند وصل می‌شود.

  • صفحه محصول / کارت فروشگاه: اولین تگ = نام و لینک برند
  • آرشیو برند: /product-tag/... با tax_query
  • فیلتر «برند» و جستجوی «شرکت‌ها»: روی product_tag
  • ACF آدرس_برند: رابطه نیست — لوگوی URL یا نام پشتیبان
  • نوار برند هوم‌پیج: لوگو و لینک‌های هاردکد به /product-tag/...

فاز ۰ — آماده‌سازی (بدون تغییر رفتار سایت)

تغییرات

  1. لیست همه product_tagها: نام، slug، term_id، تعداد محصول، لوگو، توضیح
  2. جدول نگاشت: old_slug → new_brand_slug (معمولاً همان slug)
  3. بک‌آپ دیتابیس + فایل‌های تم/افزونه
  4. تأیید استیجینگ یا پنجره نگهداری روی پروداکشن

تست

  • لیست تگ‌ها کامل است
  • بک‌آپ حداقل یک‌بار روی استیج چک شده (اگر ممکن است)
ریسک خیلی کم

فاز ۱ — ثبت CPT برند خالی (بدون ریدایرکت)

تغییرات

  1. ثبت CPT brand (یا lk_brand) در child theme
  2. عمومی، rewrite slug = brand، پشتیبانی title / editor / thumbnail / excerpt
  3. برچسب منو فارسی: «برندها»
  4. فیلدهای ACF/متا برای لوگو و توضیح (معادل فیلدهای تگ)
  5. هنوز تگ حذف نشود، ریدایرکت نباشد، UI محصول عوض نشود

تست

  • منوی «برندها» در ادمین دیده می‌شود
  • ساخت یک برند پیش‌نویس؛ URL شبیه /brand/test-slug/
  • صفحات محصول هنوز برند را از تگ نشان می‌دهند
  • /product-tag/... مثل قبل کار می‌کند
  • خانه / فروشگاه / محصول بدون fatal error
اگر چیزی شکست، همین‌جا متوقف شوید.

فاز ۲ — مهاجرت محتوا (تگ → پست برند)

تغییرات

  1. اسکریپت یک‌بارمصرف / صفحه ادمین «Migrate brands from tags»
  2. برای هر تگ: ساخت پست برند — نام→title، slug→slug، توضیح→content
  3. کپی لوگو/thumbnail تگ → تصویر شاخص یا ACF
  4. متای نگاشت روی برند: _lk_source_tag_id و _lk_source_tag_slug
  5. تگ‌ها سر جایشان بمانند (محصول‌ها هنوز به تگ وصل‌اند)

تست

  • تعداد برند ≈ تعداد تگ
  • ۱۰ برند نمونه: عنوان، slug، لوگو، توضیح درست
  • متای نگاشت روی هر برند هست
  • محصول‌ها هنوز فقط از طریق تگ وصل‌اند
  • /brand/{slug}/ ممکن است تا فاز ۳ قالب نداشته باشد — OK اگر CPT هست
هیچ تگی را هنوز پاک نکنید.

فاز ۳ — قالب صفحه برند (بدون گرید محصول)

تغییرات

  1. تمپلیت لایت single برند (شبیه کروم آرشیو تگ فعلی)
  2. لیست محصولات روی صفحه برند: خالی / stub — فقط هیرو + توضیح + لوگو
  3. اختیاری: ایندکس /brand/ برای لیست همه برندها

تست

  • مثلاً /brand/merck/ هیرو/لوگو/متن دارد
  • لیست محصول هنوز نیست (عمدی)
  • خانه / فروشگاه / آرشیو تگ قدیمی بدون تغییر
  • موبایل OK

فاز ۵ — ریدایرکت product_tag → brand

تغییرات

  1. روی template_redirect برای is_product_tag()
  2. پیدا کردن برند با متای نگاشت / slug
  3. 301 به /brand/{slug}/
  4. تگ‌ها در DB بمانند تا اتصال محصول هنوز کار کند

تست

  • /product-tag/merck/ → ۳۰۱ → /brand/merck/
  • یک پرش (بدون زنجیره دوتایی)
  • تگ بدون نگاشت: تصمیم از قبل (۴۰۴ نرم یا آرشیو موقت)
  • بعداً در Search Console خطای کراول را رصد کنید
بعد از این فاز، URLهای قدیمی برند ریدایرکت می‌شوند؛ داخل سیستم محصول هنوز با تگ کار می‌کند.

فاز R — رابطه محصول ↔ برند

وضعیت: خالی. تا وقتی این بخش را پر نکنید، فازهای ۷ و ۸ اجرا نمی‌شوند.

چه چیزی را باید مشخص کنید

  • نوع رابطه: A) متای محصول _lk_brand_id · B) ACF relationship · C) تاکسونومی جدید · D) دیگر
  • یک برند برای هر محصول یا چند برند؟
  • اجباری یا اختیاری؟
  • مهاجرت: اولین تگ فعلی چطور به فیلد جدید کپی شود؟
  • اگر محصول چند تگ دارد چه شود؟
  • UI ادمین: انتخاب برند کجا باشد؟

کارهای مسدود تا پر شدن فرم

  • بج / لینک برند روی محصول و کارت از CPT
  • گرید محصول روی صفحه برند
  • فیلتر فاست برند بر اساس CPT
  • ثبت اتوماتیک AI بر اساس برند
  • اسکوپ برند در Attribute Price Editor
  • قطع وابستگی به product_tag به‌عنوان برند

چه چیزی قبل از رابطه محصول «تمام» حساب می‌شود؟

فازهای ۷–۹ را قبل از تکمیل و تست فاز R اجرا نکنید.

با خیال راحت می‌توانید فازهای ۰ تا ۶ را تمام کنید و داشته باشید:

  • CPT برند
  • محتوای مهاجرت‌شده
  • صفحات /brand/{slug}/ (بدون گرید محصول)
  • لوگوهای خانه → CPT
  • URL تگ قدیمی ۳۰۱ → برند
  • جستجو به سمت برندها

محصول‌ها تا تعریف فاز R همچنان از product_tag استفاده می‌کنند.
