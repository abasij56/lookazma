برنامه کامل: product_tag → product_brand

مسیر هیبرید: تاکسونومی اختصاصی برند با URL /brand/{slug}/ + فیلدهای ACF روی ترم + اتصال native محصول. هر فاز: تغییرات و تست. رابطه محصول جداگانه طراحی نمی‌شود — همان ترم است.

قفل‌شده

تصمیم‌های این طرح

  • تاکسونومی: product_brand (نام فنی انگلیسی)
  • برچسب ادمین فارسی: «برندها»
  • Rewrite: brand → URL به شکل /brand/merck/
  • متصل به product (مثل تگ امروز)
  • لوگو و فیلدهای اضافه با ACF روی ترم برند
  • ۳۰۱ از /product-tag/{slug}/ به /brand/{slug}/
  • همه تگ‌های فعلی محصول = برند
  • دسته محصول (product_cat) دست نخورده می‌ماند
  • نوار برند خانه از product_brand پر می‌شود
Taxonomy: product_brand URL: /brand/{slug}/ Product link: wp_term_relationships (native) Fields: ACF on term (logo, extras…) Redirect: /product-tag/{slug}/ → 301 → /brand/{slug}/

وضعیت فعلی

  • برند = product_tag
  • صفحه محصول / کارت: اولین تگ = نام و لینک برند
  • آرشیو: /product-tag/...
  • فیلتر «برند» و جستجوی شرکت‌ها: روی تگ
  • ACF آدرس_برند: رابطه نیست (لوگو/نام پشتیبان)
  • هوم‌پیج: لینک‌های هاردکد به /product-tag/...
  • AI auto-submit و Price Editor: اسکوپ با تگ

هدف نهایی (وقتی همه فازها تمام شد)

کاربر

صفحه /brand/merck/ با لوگو، توضیح و گرید محصول؛ بج برند روی محصول به همین URL؛ فیلتر برند در فروشگاه.

ادمین

منوی «برندها»؛ روی محصول باکس برند به‌جای تگ‌های برند؛ AI و قیمت‌گذاری بر اساس product_brand.

تگ محصول دیگر نقش برند ندارد (یا خالی/حذف می‌شود طبق فاز ۱۰).

فاز ۰ — آماده‌سازی

تغییرات

  1. خروجی لیست همه product_tag: term_id، نام، slug، تعداد محصول، لوگو، توضیح
  2. جدول نگاشت: old_slug → brand_slug (معمولاً همان)
  3. قانون چندتگ: کدام ترم برند اصلی است؟ (پیشنهاد: همه تگ‌ها به برند کپی شوند؛ «اولین تگ» همچنان برای بج پیش‌فرض)
  4. بک‌آپ دیتابیس + فایل‌ها
  5. ثبت permalinkها بعد از هر فاز دارای rewrite را در چک‌لیست بگذارید

تست

  • لیست تگ‌ها کامل است
  • تعداد برند تقریبی و برندهای مهم (Merck، مجللی، نوترون، …) مشخص‌اند
  • بک‌آپ موجود است

فاز ۱ — ثبت تاکسونومی product_brand

تغییرات

  1. ثبت taxonomy روی product: public، show_ui، show_admin_column، rewrite slug = brand، hierarchical = false (مثل تگ)
  2. برچسب‌ها فارسی در ادمین
  3. گروه فیلد ACF برای ترم برند: لوگو، فیلدهای اختیاری (کشور، لینک رسمی، …)
  4. هنوز ریدایرکت نباشد؛ هنوز محصول‌ها فقط تگ داشته باشند
  5. یک‌بار flush rewrite (Settings → Permalinks → Save)

تست

  • منوی «برندها» دیده می‌شود
  • ساخت ترم تست؛ URL پیش‌نمایش /brand/test-slug/
  • فیلدهای ACF روی ترم ذخیره می‌شوند
  • فروشگاه / محصول / تگ قدیمی بدون fatal
  • دسته‌های شیمیایی بدون تغییر
اگر rewrite کار نکرد، دوباره Permalinks را Save کنید.

فاز ۳ — اتصال محصولات به product_brand

این همان «رابطه محصول» است — native، بدون فاز R جدا.

تغییرات

  1. اسکریپت مهاجرت: برای هر محصول، تگ‌هایش را بخوان؛ ترم برند متناظر را wp_set_object_terms کن
  2. حالت پیشنهادی گذار: دوگانه — هم تگ هم برند روی محصول بماند تا فازهای بعد پایدار شوند
  3. لاگ محصولات بدون تگ / تگ بدون نگاشت
  4. اجرای مجدد امن باشد (idempotent)

تست

  • محصول نمونه Merck هم تگ Merck دارد هم برند Merck
  • شمارش: محصولات دارای برند ≈ محصولات دارای تگ برند
  • محصول بدون تگ در لاگ مشخص است
  • فرانت هنوز از تگ می‌خواند (تا فاز ۵) — سایت نشکند
بعد از این فاز، می‌توانید با tax_query روی product_brand محصولات را لیست کنید — حتی قبل از تعویض UI.
